# **habit_tracker**
## **Coursework**

### Описание
~ Проект представляет собой API для трекера привычек с возможностью интеграции с Telegram для отправки напоминаний.

### Функционал
~ Управление привычками (CRUD)

~ Поддержка приятных и полезных привычек

~ Публичные и приватные привычки

~ Пагинация списка привычек (5 на страницу)

~ Авторизация и регистрация пользователей

~ Интеграция с Telegram для напоминаний

~ Документирование API

### Модели
~ Habit
~ CustomUser

### Валидация
~ Нельзя указывать одновременно вознаграждение и связанную привычку

~ У приятной привычки не может быть вознаграждения или связанной привычки

### Эндпоинты

~ Регистрация / Авторизация

~ Управление привычками (создание, редактирование, удаление, просмотр)

~ Просмотр публичных привычек

### Интеграция с Telegram
~ Реализована отправка напоминаний о привычках с помощью API Telegram.

### Безопасность
~ Настроен CORS для корректной работы фронтенда.

### Документация
~ Документация API доступна и настраивается для удобства работы фронтенд-разработчиков.
